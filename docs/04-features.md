- 카메라 권한을 거부한 경우 — 근거: 일반적인 모바일 카메라 접근 UX
- 이미지 업로드 중 네트워크가 끊긴 경우 — 근거: SHY 스펙 Task 3-1(S3 업로드)
- OCR API 호출이 실패하거나 쿼터를 초과한 경우 — 근거: SHY 스펙 "OCR 엔진: Naver Clova OCR 또는 Google Cloud Vision API"(외부 API 의존)
- 사진이 흐리거나 어두워 텍스트 인식 자체가 안 되는 경우 — 근거: SHY 스펙 Task 3-2 DoD "실제 영수증 사진 3~5장으로 테스트 시 금액 필드 90% 이상 정확 추출"이 전제하는 실패 가능성
- 그룹을 선택하지 않고 촬영해 개인 지출로만 등록되는 경우(공유 안 됨) — 근거: SHY 스펙 Task 2-2 `isShared` 기본값 false
(위 5개는 인수 조건 작성 시 참고자료로 남김)

**"같은 요구(R8)를 다른 방식으로 만족시키는 기능은?"**
- 수기 입력 폼에서 최근 사용 카테고리·금액을 자동완성으로 제안(OCR 없이 빠른 수기 입력) — 근거: SHY 스펙 Task 2-2 ExpenseForm

**"같은 요구(R15, 정산)를 다른 방식으로 만족시키는 기능은?"**
- 자동 계산 없이 그룹원별 지출 합계만 나란히 보여주는 비교 표(계산은 사람이 함) — 근거: SHY 스펙이 "정산/더치페이 자동계산"을 제외(향후 확장)로 명시한 것과 절충 가능
