## 단계 (As-Is → To-Be)
| S | 단계 | 행동(As-Is) | 감정 | 불편 | To-Be 한 줄 |
|---|---|---|---|---|---|
| S1 | 그룹 생성 · 참여 | 그룹장이 그룹 이름 · 유형을 정해 만들고 초대코드를 공유, 그룹원은 코드로 들어온다 | 특별한 감정 없음 · 무덤덤함 | 딱히 불편하진 않음 | 초대코드 공유 방식은 유지하고, 연락처로 초대하는 방식도 추가되면 좋겠음 |
| S2 | 지출 발생(수기 기록) | 영수증을 받거나 결제 후, 그 자리에서 또는 나중에 기억해서 적는다 | 나중에 깜빡할까봐 신경 쓰임 · 불안함 | 나중으로 미루면 잊어버리거나 영수증을 잃어버린다 | 촬영 한 장으로 즉시 자동 기록됨(SHY 스펙 Phase 3 목표) |
| S3 | 지출 출처 확인 | "토스페이 지출"처럼 뭉뚱그려 뜨는 결제내역을 보고 실제 무엇을 샀는지 떠올리려 한다 | [?] | 출처를 알 수 없는 지출이 나온다 | 결제 캡쳐를 올리면 가맹점명 · 금액이 자동으로 채워짐 |
| S4 | 영수증 촬영 자동 등록(OCR) | 카메라로 영수증을 찍으면 AI가 금액 · 가맹점을 인식해 지출로 자동 등록한다 | [?] | (정상 동작 시 불편 없음 — 실패 시 S5로 이어짐) | 이미 To-Be 상태(SHY 스펙 Phase 3 필수) |
| S5 | 인식 실패 항목 확인 · 수정 | OCR이 실패한 항목은 "확인 필요" 배지로 표시돼 나중에 손으로 고친다 | 귀찮음 · 짜증남 | 잘못 적은(또는 인식 실패한) 지출을 다시 찾는 데 시간이 든다 | 그 지출 항목을 눌러 바로 수정 · 삭제할 수 있음 |
| S6 | 공유 여부 정하기 | 집단 성격 지출(부부 · 커플 · 친구관계 등)이면 그룹과 공유, 그 외는 나만 보기(자동 판단) | 특별히 고민하지 않음(자동으로 정해짐) | 없음(관계 기준 자동 판단) — 단, 애매한 경우(원래 개인 지출인데 그룹원 한 명에게만 보여주고 싶은 경우)는 지금 기준으로 못 다룰 수 있음 | 입력 화면에서 토글 하나로 정함(SHY 스펙 Task 2-2) |
| S7 | 그룹 지출 확인(피드) | 누가 얼마를 썼는지 각자 물어보거나 단톡방을 뒤져 취합한다(또는 각자 은행 앱에서 자기 내역만 봄) | 답답함 · 번거로움 | 흩어져 있어 취합에 시간이 들고, 가맹점 이름만 나와 실제 무엇을 샀는지 모르며, 그룹원끼리 공유해서 보는 것 자체가 안 됨 | 그룹 피드에서 시간순으로 한 번에 봄(SHY 스펙 Phase 5) |
| S8 | 지출 오기입 수정 · 삭제 | 금액 · 카테고리를 잘못 적었을 때 다시 찾아 고친다 | 귀찮음 · 짜증남 | 잘못 적은 지출을 다시 찾는 데 시간이 든다 | 본인이 등록한 지출만 수정 · 삭제할 수 있음(타인 것은 그룹장이라도 불가) |
| S9 | 그룹 안에서 정산(더치페이) | 그룹 구성원끼리 나눠 낸 금액을 손으로(카카오톡 정산하기 등으로) 계산한다 | 답답함 | 각자 낸 내역을 직접 다 더해서 정산해야 한다 | [?] (SHY 스펙은 "제외(향후 확장)"으로 명시 — MVP 범위 밖일 가능성, 팀 확인 필요) |
