## 상태값
1. **그룹장(Role) 상태** — 그룹장(OWNER) 있음 → 그룹장이 그룹을 나가기 전 그룹원 중 한 명을 새 그룹장으로 지정 → 지정된 사람이 새 OWNER로 전환된 뒤에만 기존 그룹장이 나갈 수 있음 — 근거: 팀 인터뷰 답변("나갈 때 그 사람이 다른 사람에게 그룹장 지정") · 02-workflow.md 상태값1 갱신 · F18(그룹장 위임) · P10
   - 그룹원이 본인(그룹장) 혼자뿐이면 위임 없이 그룹을 나갈 수 있고, 이때 그룹과 그 안의 지출 데이터는 함께 삭제된다
2. **지출 인식 상태** — 정상 등록(사용자가 확인한 카테고리) → OCR/캡쳐 인식 실패 시 "확인 필요" 상태로 자동 전환 → 사용자가 F10에서 수정하면 다시 정상 등록 상태로 전환 — 근거: SHY 스펙 Task 3-2 · 3-3
