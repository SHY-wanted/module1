5개 탭(홈 · 그룹 · 중앙 강조 아이콘 · 지출내역 · 마이페이지)이 2b·5a·5b·6·7·7b·10 화면에 공통으로 나타난다.

## 화면 전환 방식
> 2026-09-11 팀 결정: 화면마다 라우트를 만들지 않는다. `app/page.tsx` 한 페이지가 화면들을 상태로 들고 전환한다. 위 「화면 목록」 표의 진입 경로·다음 화면(액션)은 그대로다 — 이동이 일어나는 방식만 페이지 이동에서 화면 전환(애니메이션)으로 바뀐다.
> 한 페이지로 합친 이유: 라우트를 화면마다 두면 페이지 이동마다 이전 화면이 언마운트되는데, 아래 "화면 쌓기"는 여러 겹이 동시에 마운트된 채 하나씩 벗겨지는 세로 슬라이드를 요구하고 "탭 전환"은 120ms 크로스페이드를 요구한다 — 둘 다 이전 화면이 전환 도중 화면에 남아 있어야 해서, 라우트 이동이 아니라 한 페이지 안의 상태 전환으로 구현한다.

이동은 세 종류이고 애니메이션이 다르다(로그인 전 화면 전환은 2026-09-11에 세 번째 종류로 확정됨).

| 종류 | 대상 | 애니메이션 | 뒤로가기 |
|---|---|---|---|
| (1) 탭 전환 | 「하단 탭 내비게이션」의 홈(2b)·그룹(5a)·지출내역(7)·마이페이지(10) 사이 | 슬라이드 없음, 120ms 크로스페이드 | 개념 없음(탭끼리는 뒤로가기가 없음) |
| (2) 화면 쌓기 | 탭 위에 얹히는 화면 | 세로 슬라이드 280ms · cubic-bezier(0.32, 0.72, 0, 1) — 앞으로 가면 아래에서 올라오고, 뒤로 가면 아래로 내려간다. 여러 겹 쌓이고 하나씩 벗겨진다. 쌓인 화면에는 하단 탭이 보이지 않는다 | 한 겹씩 벗겨짐 |
| (3) 로그인 전 화면 전환(신규, 2026-09-11 팀 결정) | 0·1·1b·2·2a 사이(아직 탭 셸이 없음) | 애니메이션 없이 즉시 전환 | 별도 스택 관리 없음(일반 브라우저 동작) |
