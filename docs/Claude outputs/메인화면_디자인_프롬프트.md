# 공유 가계부 앱 - 메인 화면 디자인 프롬프트

## 🎯 디자인 목표
**개인 지출을 관리하고, 그룹을 생성할 수 있는 랜딩 화면**

현재 로그인/회원가입 후 바로 "어떤 모임인가요?" 그룹 생성-모임 선택 창이 나오는데, 이를 개선하기 위해 **메인 화면**을 먼저 배치합니다. 사용자는 여기서:
- 자신의 개인 지출을 확인하고 수정/정리할 수 있고
- **"그룹 만들기" 버튼**을 눌러야만 그룹 생성 화면으로 이동합니다

---

## 📱 화면 구성 요소

### 1️⃣ **헤더/상단**
- 앱 로고 또는 브랜드명 (왼쪽)
- 사용자 프로필/설정 아이콘 (오른쪽)
- 간단한 환영 문구 (예: "홍길동님, 오늘 지출을 기록해보세요")

### 2️⃣ **이달 지출 요약 카드** (하이라이트 섹션)
- **이번 달 총 지출액**: 큰 텍스트로 강조
- **지난달 대비** 또는 **예산 대비** 비교 (선택사항)
- 카테고리별 지출 비중 (간단한 도넛 차트 또는 프로그레스 바)
  - 예: 🍔 식비 35%, 🏪 생활용품 20%, 🚗 교통 15% 등
- 배경색: 밝고 긍정적인 톤

### 3️⃣ **빠른 액션 버튼 영역** (3개)
배치 방식: 3개 버튼을 가로로 나열 (또는 카드 형식)

| 버튼 | 동작 | 설명 |
|-----|------|------|
| ➕ **지출 추가** | 지출 입력 폼으로 이동 | 빠른 기록 (수기 입력) |
| 📷 **영수증 촬영** | 카메라/갤러리 (OCR) | 영수증 자동 인식 등록 |
| 👥 **그룹 만들기** | 그룹 생성 → 모임 선택 | **핵심: 이 버튼으로만 그룹 생성 화면 진입** |

### 4️⃣ **최근 지출 목록** (스크롤 가능)
리스트 형식 (또는 카드 형식)으로 최근 지출 5~10개 표시

각 항목:
- **날짜** (예: "오늘", "어제", "3일 전")
- **카테고리 아이콘** + **카테고리명** (예: 🍔 식비)
- **지출액** (오른쪽 정렬, 빨간색 또는 강조색)
- **메모/가맹점명** (작은 회색 텍스트, 선택사항)
- **상태 배지** (필요시):
  - ✅ 정상 (기본)
  - ⚠️ 확인 필요 (OCR 실패 시)
  - 🔄 공유중 (그룹에 공유된 지출)

터치 시 동작:
- 항목 클릭 → 지출 상세/수정 폼 진입
- 스와이프 → 삭제 옵션 (선택사항)

### 5️⃣ **필터/정렬 바** (선택사항, 목록 위)
- 카테고리 필터 (드롭다운)
- 날짜 범위 필터 (이번 달/지난달/커스텀)
- 정렬순 (최신순/금액순)

### 6️⃣ **하단 네비게이션** (필요시)
- 🏠 **홈** (메인 화면)
- 👥 **그룹** (속한 그룹 목록)
- 📊 **리포트** (월별 통계)
- ⚙️ **설정**

## 🎨 디자인 원칙

### 색상
- **주색상**: 앱의 브랜드 색 (신뢰감과 친화력)
- **강조색**: 지출 항목 (빨강, 주황 등 → 돈이 빠져나가는 느낌 표현)
- **보조색**: 수입, 목표 달성 등 (초록, 파랑 등)
- **배경**: 밝고 깔끔한 톤 (하얀색 또는 연한 회색)
- **텍스트**: 진한 회색/검정 (가독성 최우선)

### 타이포그래피
- **헤더**: 큼, 굵게 (18~24px, 제목과 수치용)
- **본문**: 중간 (14~16px, 일반 텍스트)
- **작은 텍스트**: 12~13px (메모, 날짜)

### 레이아웃
- **상단 → 하단**: 시각적 계층을 명확히 (중요도 높은 것부터)
- **여백**: 충분한 여백으로 답답하지 않게
- **반응형**: 모바일 퍼스트 (작은 화면부터 설계)

### 인터랙션
- **버튼 호버/터치**: 피드백이 명확하게 (색상 변화, 애니메이션)
- **로딩 상태**: 지출 추가/수정 시 로딩 표시
- **빈 상태**: 첫 사용 시 "지출이 없어요" 메시지 + 친절한 가이드

## 📐 사용자 흐름

```
로그인/회원가입
    ↓
[ 메인 화면 ]  ← 여기가 새로 추가되는 부분
    ↓
    ├─ "지출 추가" 버튼 → 지출 입력 폼 → 저장 → 목록에 반영
    ├─ "영수증 촬영" 버튼 → 카메라/갤러리 → OCR 자동 인식 → 저장
    └─ "그룹 만들기" 버튼 → 그룹명/유형 입력 → 그룹 생성-모임 선택 화면
           ↓
        (기존 흐름 시작)
```

---

## 💡 고려사항

1. **첫 방문 사용자**: 지출이 아무것도 없을 때 → 온보딩 메시지 표시 (예: "첫 지출을 추가해보세요!")
2. **그룹 비멤버 상태**: 이 메인 화면에서는 개인 지출만 표시 (그룹 지출은 나중)
3. **"그룹 만들기" 버튼**: 눈에 띄도록 배치 (하지만 "지출 추가"보다 덜 중요)
4. **메모리/성능**: 목록은 처음 5~10개만 로드, 스크롤 시 더 불러오기 (무한 스크롤 또는 페이지네이션)
5. **다크 모드**: 밝은 배경과 진한 텍스트가 어둡게 반전되도록 (선택사항)

## 🎯 핵심 메시지

> **"나의 지출을 정리하는 공간"**
> 
> 이 메인 화면은 사용자가 **개인적으로 지출을 관리**하는 중심 무대입니다.  
> 여기서 편하게 지출을 기록하고 수정하고, 필요할 때만 **"그룹 만들기"**를 눌러 다른 사람과 공유할 수 있도록 유도합니다.
